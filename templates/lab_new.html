🚀 Universal Project Template

All new projects start with our optimized Flask + HTML template running on port 8000, alongside a powerful IDE in VS Code.

✨ What's Included

  • Flask Web Server — Runs automatically on port 8000
  • HTML/CSS/JS Support — Full static file serving and templating
  • Python Environment — Pre-configured venv with pip
  • VS Code IDE — Web-based editor on port 8443
  • Git Repository — Built-in version control

🛠️ Getting Started

  1. Create your project
  2. Click "Edit Code" to open VS Code
  3. Modify templates/index.html and app.py
  4. Click "Open Page" to see your app live
  5. Commit your changes to Git

🔧 Customize It

Use the Flask app to build anything:

  • Web applications with multiple pages
  • REST APIs with JSON responses
  • Real-time apps with WebSockets
  • Database-backed systems
  • Or import other Python frameworks
