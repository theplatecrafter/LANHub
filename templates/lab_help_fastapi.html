FastAPI Project Setup

FastAPI is a modern, fast Python web framework. Your project has a basic FastAPI app set up.

Project Structure

  • app.py - Main FastAPI application file
  • requirements.txt - Python dependencies
  • venv/ - Virtual environment (auto-created)

Getting Started

  1. Click "Deploy" to start your container
  2. Edit app.py to add your routes and endpoints
  3. Install dependencies: pip install package-name
  4. Add new packages to requirements.txt
  5. Click "Preview App" to test your running API

Common Tasks

Add a GET endpoint: 
@app.get("/items/{item_id}")
async def get_item(item_id: int):
    return {"item_id": item_id}
Add a POST endpoint: 
from pydantic import BaseModel

class Item(BaseModel):
    name: str
    price: float

@app.post("/items/")
async def create_item(item: Item):
    return item
Query parameters: 
@app.get("/search/")
async def search(q: str, skip: int = 0, limit: int = 10):
    return {"q": q, "skip": skip, "limit": limit}

Install Dependencies

To add a new Python package, use the terminal in VSCode:

pip install package-name
pip freeze > requirements.txt

Redeploy your project after adding dependencies.
