◈ Local Area Network Hub

Welcome to HansHub

A self-hosted, all-in-one platform for your local network. Chat, play games, share files, run polls, and manage your server — all from a single browser tab, with no internet required.

🐍 Python + Flask ⚡ Real-time Socket.IO 🌐 LAN-first 🎮 5 Games included 🔒 Password protection

◈ What is it?

🏠 Self-hosted

Runs entirely on your own hardware — a Raspberry Pi, a spare laptop, or a full server. No cloud, no subscriptions, no account required. Your LAN, your rules.

⚡ Real-time

Built on Flask-SocketIO for instant two-way communication. Messages, game moves, server stats, and board updates all push live to every connected browser.

🌍 No domain required

Access HansHub from anywhere — even outside your LAN — using the free GitHub Pages redirector. No DNS, no domain purchase, no port-forwarding wizard needed.

🎨 14 Themes

Switch between Mission Control, Kawaii, Vaporwave, Matrix, Blueprint, Outrun, Windows 95, Game Boy, DOS, and more — saved per-browser in localStorage.

🔐 Access Control

🌐 Public Mode

Anyone on your network (or reachable via the redirector) can open HansHub and start using it immediately. No login, no barrier — just open the URL and you're in. Ideal for LAN parties and fully trusted networks.

No password required
🔒 Password Mode

When enabled, visitors must enter a server password before they can see anything. The password is set once by the server administrator and applies to all users. Sessions persist across browser refreshes so users only type it once per device.

🌍 Accessing from Anywhere

🔗 Free GitHub Pages Redirector

HansHub ships with a companion GitHub Pages site you can fork for free. It acts as a public-facing bookmark that silently forwards visitors to your server's local IP — so friends outside your house can reach your HansHub without you buying a domain or configuring dynamic DNS.

The redirector stores nothing and proxies nothing — it's a single HTML file that just points a browser at your IP. All traffic still goes directly to your machine.

✓ Free forever ✓ No domain purchase ✓ No proxy / no data routing

💡 Design Philosophy

HansHub was built around one idea: everything you'd want to do on a local network should live in one place, and it should feel good to use. Not a collection of separate tools duct-taped together, but a cohesive platform where chat, games, files, and monitoring share the same design language, the same theme system, and the same real-time backbone.

The stack is deliberately simple and dependency-light. SQLite instead of Postgres. Pure Python game logic instead of external binaries. A built-in OUI table instead of an API call. The server can run on a Raspberry Pi 4 with 2 GB of RAM and serve an entire household without breaking a sweat.

Access control is intentionally flexible. Public mode removes every barrier so a LAN party can get started in seconds. Password mode adds a single shared gate for networks where you want a little more control — without forcing individual accounts or a sign-up flow on anyone.

All game logic (Tetris, Chess, UNO) runs server-side in Python as the authoritative source, with the browser handling only rendering and input. The server relays game state to all clients over Socket.IO, keeping every player perfectly in sync.
