◈ Local Area Network Hub

Welcome to LANHub

A self-hosted, all-in-one platform for your local network. Chat, play games, share files, run polls, and manage your server — all from a single browser tab, with no internet required.

🐍 Python + Flask ⚡ Real-time Socket.IO 🌐 LAN-first 🎮 Games included

◈ What is it?

🏠 Self-hosted

Runs entirely on your own hardware — a Raspberry Pi, a spare laptop, or a full server. No cloud, no subscriptions, no account required. Your LAN, your rules.

⚡ Real-time

Built on Flask-SocketIO for instant two-way communication. Messages, game moves, server stats, and board updates all push live to every connected browser.

🔒 Private by design

Everything stays on your local network. There's an optional GitHub Pages redirector so you can reach your server from outside, but the data never leaves your machine.

🎨 14 Themes

Switch between Mission Control, Kawaii, Vaporwave, Matrix, Blueprint, Outrun, Windows 95, Game Boy, DOS, and more — saved per-browser in localStorage.

⚙ Tech Stack

🐍 Python 3.13 🌶 Flask ⚡ Flask-SocketIO 🗃 SQLite 📅 APScheduler 🌿 GitPython 📊 psutil ♟ python-chess 🚫 better-profanity 🔌 Socket.IO 4.x 🎨 CSS Variables + 14 Themes 🖥 xterm.js (server console)

💡 Design Philosophy

LANHub was built around one idea: everything you'd want to do on a local network should live in one place, and it should feel good to use. Not a collection of separate tools duct-taped together, but a cohesive platform where chat, games, files, and monitoring share the same design language, the same theme system, and the same real-time backbone.

The stack is deliberately simple and dependency-light. SQLite instead of Postgres. Pure Python game logic instead of external binaries. A built-in OUI table instead of an API call. The server can run on a Raspberry Pi 4 with 2 GB of RAM and serve an entire household without breaking a sweat.

All game logic (Tetris, Chess, UNO) runs client-side in the browser. The server only handles matchmaking, room management, and relaying game events — keeping server CPU usage near zero even during active multiplayer sessions.
