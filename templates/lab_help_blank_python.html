Blank Python Project Setup

A flexible Python project template. Perfect for scripts, utilities, data processing, and experiments.

Project Structure

  • main.py - Main entry point
  • requirements.txt - Python dependencies (empty by default)
  • venv/ - Virtual environment (auto-created)

Getting Started

  1. Click "Deploy" to start your container
  2. Edit main.py with your Python code
  3. Run scripts using the VSCode terminal
  4. Install dependencies: pip install package-name
  5. Update requirements.txt with: pip freeze > requirements.txt

Using the Virtual Environment

The virtual environment is automatically activated in the VSCode terminal.

# Run your main script
python main.py

# Run a specific Python file
python scripts/utility.py

# Install a package
pip install requests

# List installed packages
pip list

Project Organization

As your project grows, organize your code:

project/
  ├── main.py
  ├── requirements.txt
  ├── utils/
  │   ├── __init__.py
  │   └── helpers.py
  ├── data/
  │   ├── input.csv
  │   └── output.csv
  └── tests/
      └── test_utils.py

Popular Libraries

  • requests: HTTP library - pip install requests
  • pandas: Data analysis - pip install pandas
  • numpy: Numerical computing - pip install numpy
  • flask: Web framework - pip install flask
  • sqlite3: Database (built-in)
