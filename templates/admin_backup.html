Danger Zone

All actions below are irreversible. Each requires multiple confirmation clicks. Read carefully before proceeding.

Clear all logs Truncates every .log file to empty. Does not affect the database or files.
Purge all IP bans Removes every IP ban record. Banned users will be able to connect immediately.
Purge all chat history Deletes every message in the global chat and all channels. Cannot be undone.
Wipe all uploaded files Deletes every file in the Dropzone and clears all upload records from the database.
Rotate secret key Generates a new SECRET_KEY. Every active session cookie becomes invalid immediately — all users including you will be logged out. You will need to log back in after this.
Reset database Drops and reinitialises the entire SQLite database. All messages, uploads, polls, feedback, bans, admin accounts, and every other record are permanently erased. configvars.json and files on disk are not affected.
Complete server removal

Stops and removes the lanhub systemd service, kills the Cloudflare tunnel, and deletes the entire project directory from disk. After this completes the server computer will have no trace of LANHub. This cannot be undone.
