Flask Project Setup

Flask is a lightweight Python web framework. Your project has a basic Flask app set up.

Project Structure

  • app.py - Main Flask application file
  • requirements.txt - Python dependencies
  • templates/ - HTML templates directory
  • venv/ - Virtual environment (auto-created)

Getting Started

  1. Click "Deploy" to start your container
  2. Edit app.py to add your routes and logic
  3. Add HTML templates in the templates/ directory
  4. Install dependencies: pip install package-name
  5. Add new packages to requirements.txt
  6. Click "Preview App" to test your running app

Common Tasks

Add a new route: 
@app.route('/hello')
def hello():
    return 'Hello, World!'
Render a template: 
from flask import render_template

@app.route('/')
def index():
    return render_template('index.html', name='World')
Handle POST requests: 
@app.route('/submit', methods=['POST'])
def submit():

Install Dependencies

To add a new Python package, use the terminal in VSCode:

pip install package-name
pip freeze > requirements.txt

Redeploy your project after adding dependencies.
