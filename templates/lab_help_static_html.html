Static HTML Project Setup

Perfect for static websites, landing pages, and single-page applications. No server-side logic needed.

Project Structure

  • index.html - Main HTML file
  • server.py - Simple Python HTTP server
  • css/ - Stylesheets directory (create as needed)
  • js/ - JavaScript files directory (create as needed)
  • images/ - Images directory (create as needed)

Getting Started

  1. Click "Deploy" to start your container
  2. Edit index.html with your HTML content
  3. Create css/, js/, and images/ directories as needed
  4. Click "Preview App" to view your website
  5. Your files are automatically served by the server

File Organization

Basic structure: 
project/
  ├── index.html
  ├── css/
  │   └── style.css
  ├── js/
  │   └── script.js
  └── images/
      └── logo.png

Common HTML5 Template

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Website</title>
    <link rel="stylesheet" href="css/style.css">
</head>
<body>
    <h1>Welcome!</h1>
    <script src="js/script.js"></script>
</body>
</html>
