Node.js Express Project Setup

Express is a minimal and flexible Node.js web framework. Perfect for REST APIs and modern web apps.

Project Structure

  • app.js - Main Express application
  • package.json - Project metadata and dependencies
  • node_modules/ - Installed npm packages

Getting Started

  1. Click "Deploy" to start your container
  2. Edit app.js to add your routes
  3. Install dependencies: npm install package-name
  4. Dependencies are automatically added to package.json
  5. Click "Preview App" to test your running app

Common Tasks

Add a GET route: 
app.get('/hello', (req, res) => {
    res.send('Hello, World!');
});
Add a POST route: 
app.post('/submit', (req, res) => {
    const data = req.body;
    res.json({ received: data });
});
Serve static files: 
app.use(express.static('public'));
// Now files in public/ are accessible as /file.html

Managing Dependencies

Use npm to install and manage packages:

# Install a new package
npm install package-name

# Install a dev dependency
npm install --save-dev package-name

# List installed packages
npm list

# Update packages
npm update

npm Scripts

Edit package.json scripts for custom commands:

"scripts": {
    "start": "node app.js",
    "dev": "nodemon app.js",
    "test": "jest"
}

Then run: npm start, npm run dev, etc.

Popular npm Packages

  • express: Web framework
  • nodemon: Auto-restart on file changes - npm install --save-dev nodemon
  • cors: CORS support - npm install cors
  • axios: HTTP client - npm install axios
  • dotenv: Environment variables - npm install dotenv
