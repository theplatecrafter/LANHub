🚀 ユニバーサルプロジェクトテンプレート

新しいプロジェクトはすべて、ポート8000で動作する最適化された Flask + HTML テンプレートと、VS Codeの強力なIDEを備えています。

✨ 含まれるもの

  • Flask Webサーバー — ポート8000で自動実行
  • HTML/CSS/JSサポート — 静的ファイル配信とテンプレート完全対応
  • Python環境 — 仮想環境とpipをプリセット
  • VS Code IDE — ポート8443のWebベースエディタ
  • Gitリポジトリ — 組み込みバージョン管理

🛠️ はじめに

  1. プロジェクトを作成
  2. 「コードを編集」をクリックしてVS Codeを開く
  3. templates/index.html と app.py を編集
  4. 「ページを開く」をクリックしてアプリをライブ確認
  5. 変更をGitにコミット

🔧 カスタマイズ

Flaskアプリを使って何でも構築できます：

  • 複数ページのWebアプリケーション
  • JSONレスポンスのREST API
  • WebSocketを使ったリアルタイムアプリ
  • データベース駆動システム
  • 他のPythonフレームワークの導入も可能
