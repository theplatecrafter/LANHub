# LANHub Scripts and Utilities

This directory contains utility scripts and development tools for LANHub.

## Contents

- **dev_tools.ipynb** - Jupyter notebook with development utilities and testing tools
- **main_update.json** - Configuration for main update system

## Usage

### dev_tools.ipynb

Interactive Python notebook for development and testing:

```bash
# Install Jupyter
pip install jupyter

# Launch notebook
jupyter notebook scripts/dev_tools.ipynb
```

Use for:
- Testing code snippets
- Database queries
- Development debugging
- Quick prototyping

## Maintenance

Scripts in this directory are:
- Optional utilities, not part of core application
- For development only, not production deployment
- Safe to delete if not needed
